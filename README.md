# deskbeat

Music widgets for the Windows desktop.

Download the latest installer (`deskbeat-setup-x.y.z.exe`) from [Releases](https://github.com/hlnyel/deskbeat-releases/releases/latest).
Installed apps find new versions here on their own and ask before updating.

This repository only holds release files.
